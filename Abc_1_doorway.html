Configuración del motor de IA

¿Dónde consigo una clave gratuita? / ¿Cómo activo Ollama o LM Studio?
ProveedorCómo empezar
Google AI Studio (Gemini)Entra en aistudio.google.com con tu cuenta Google → "Get API key". Generosa capa gratuita, buen español.
GroqRegístrate en console.groq.com → API Keys → Create API Key.
OpenRouterCuenta en openrouter.ai → Keys. En su catálogo, elige un modelo cuyo nombre termine en :free y ponlo en el campo Modelo.
GLM (Z.ai)Cuenta en z.ai → plataforma de API. Verifica qué modelos tiene habilitados tu plan/región y ajusta el nombre en el campo Modelo.
OllamaInstala desde ollama.com, luego en terminal: ollama pull qwen2.5:7b y ollama serve. Si "Probar conexión" da error 403, arranca Ollama permitiendo el origen: en Windows set OLLAMA_ORIGINS=* antes de ejecutarlo; en macOS launchctl setenv OLLAMA_ORIGINS "*"; en Linux, añade Environment="OLLAMA_ORIGINS=*" al servicio. La API key no es necesaria.
LM StudioDescarga el modelo desde su catálogo, ve a la pestaña "Developer / Local Server" → Start (puerto 1234) y activa "Enable CORS"/"Serve on local network" si lo pide. En el campo Modelo escribe el id exacto del modelo descargado. La API key no es necesaria.

Los endpoints locales (Ollama, LM Studio) no envían tu tesis a internet: todo se procesa en tu computadora. Los gratuitos con cuenta sí envían el texto al proveedor.

Nota de seguridad: en un navegador la clave es visible en la pestaña de Red. Para un despliegue compartido con varias personas, usa la opción "proxy propio" (una función serverless que guarda la clave en el servidor). Algunos proveedores bloquean llamadas directas desde navegador (CORS): si la prueba falla por eso, prueba con otro proveedor de la lista o con un proxy.
